# ⌨️ Typing Test Pro

Typing Test Pro is a modern and interactive web application designed to help users improve their typing speed and accuracy. Built using HTML, CSS, and JavaScript, this project provides a real-time typing experience with performance tracking and customizable difficulty levels.

---

## 🚀 Features

- 🎯 Multiple difficulty levels (Easy, Medium, Hard)
- ⏱ Custom time selection (1 min to 30 mins)
- ⚡ Real-time WPM (Words Per Minute) calculation
- 🎯 Accuracy tracking
- ✅ Highlights correct and incorrect characters
- 📊 Dynamic text generation based on selected time
- 🎨 Responsive and modern UI design
- 🔄 Interactive typing experience with live feedback

---

## 🛠️ Technologies Used

- HTML5 – Structure of the application  
- CSS3 – Styling and responsive design  
- JavaScript (Vanilla JS) – Logic and interactivity
